The emulator: sbc-emu

Written for this project, BSD 3-Clause licence. Source: github.com/joakimeriksson/sbc-emu. The page and the snapshot are built from it by tools/site-build.sh.

Raspberry Pi 4: Linux kernel

  • Linux 6.18.50-v8+, the Raspberry Pi kernel kernel8.img from Raspberry Pi firmware release 1.20260915, unmodified (SHA-256 f80aa8bb…da68b).
  • Licence: GNU GPL version 2.
  • Source: raspberrypi/linux at commit cff533a, the commit that release names in extra/git_hash.

Raspberry Pi 4: BusyBox

  • BusyBox 1.36.1, Alpine Linux's busybox-static-1.36.1-r31 package for aarch64, unmodified (SHA-256 1d8e7a7f…cfac70).
  • Licence: GNU GPL version 2.
  • Source: busybox-1.36.1.tar.bz2, with Alpine's build recipe and patches in aports, 3.20-stable.

Raspberry Pi 4: start-up script

The initramfs's /init is a short shell script written for sbc-emu (sbc-emu mkinitramfs), under the project's BSD licence.

Orange Pi One: Linux kernel and device tree

  • Linux 6.18.64, Alpine Linux's linux-lts-6.18.64-r0 package for armv7: its vmlinuz-lts and its sun8i-h3-orangepi-one.dtb, unmodified (SHA-256 of the package 57be01c3…7046aff).
  • Licence: GNU GPL version 2.
  • Source: linux-6.18.64.tar.xz from kernel.org, with Alpine's configuration and patches in aports, 3.24-stable.

Orange Pi One: initramfs

  • Alpine Linux 3.24.4 minirootfs for armhf (BusyBox, musl, apk-tools and their dependencies), unmodified, with the kernel's SD-card modules and a short /init written for sbc-emu (scripts/orangepi-one-fixture.sh).
  • Licences: GNU GPL version 2 (BusyBox, the kernel modules), MIT (musl) and others, as each package states.
  • Source: every package's recipe and patches are in aports, 3.24-stable; Alpine's source tarballs are linked from each recipe.

Tinker Board S: Linux kernel and device tree

  • Linux 6.12.107, Debian 13's linux-image-6.12.107+deb13-armmp package (version 6.12.107-1) for armhf: its vmlinuz and its rk3288-tinker-s.dtb, unmodified (SHA-256 of the package 9db6efc1…4293a4380).
  • Licence: GNU GPL version 2.
  • Source: Debian's linux source package, version 6.12.107-1, from snapshot.debian.org (the kernel.org release with Debian's configuration and patches).

Tinker Board S: initramfs

  • Alpine Linux 3.24.4 minirootfs for armhf, unmodified, with a short /init written for sbc-emu (scripts/tinker-board-fixture.sh). Licences and source as for the Orange Pi One's initramfs above.
