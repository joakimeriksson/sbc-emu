Raspberry Pi 4 3D demos: the snapshot

The 3D demo page resumes a snapshot of an emulated Pi 4’s memory. It holds the programs below as they were running, and parts of many others from the same system.

  • Raspberry Pi OS Lite (trixie, arm64), the 2026-10-06 image, unmodified (SHA-256 of the .img.xz 483db18a…ff422843), after its first boot. Its 703 packages are under their own licences, which each states in /usr/share/doc/package/copyright.
  • Installed on it with apt from the Raspberry Pi OS and Debian archives (scripts/raspios-gpu-setup.txt):
    • Mesa 26.2.6 (26.2.6-1~bpo13+0~rpt2), MIT licence; source: mesa_26.2.6-1~bpo13+0~rpt2.dsc in the Raspberry Pi archive.
    • glmark2 2023.01 (2023.01+dfsg-2), GNU GPL version 3; source: Debian’s glmark2 2023.01+dfsg-2.
    • kmscube (0.0.0~git20210103-1), MIT licence; source: Debian’s kmscube 0.0.0~git20210103-1.
  • Linux 6.18.50, the Raspberry Pi OS kernel package (1:6.18.50-1+rpt1), GNU GPL version 2; source: linux_6.18.50-1+rpt1.dsc in the Raspberry Pi archive.
  • Source for every other package: the same version’s source package in the Raspberry Pi archive (versions with rpt) or on snapshot.debian.org (Debian’s).

Jetson Nano: initramfs

  • Alpine Linux 3.24.4 minirootfs for aarch64, unmodified, with the board's drivers from the kernel package above (unpacked modules) and a short /init written for sbc-emu (scripts/jetson-nano-debian-fixture.sh). Licences and source as for the Orange Pi One's initramfs and the kernel above.
  • The USB and GPU drivers look for NVIDIA's firmware. None is here: the files with those names are placeholders written by scripts/jetson-nano-debian-fixture.sh and tools/nano_gpu_firmware.py, with headers and no code, because the emulator answers for the microcontrollers itself.

Jetson Nano: GPU demos

  • Mesa 25.0.7 and the libraries it needs, unmodified, from Debian 13's arm64 packages, which scripts/jetson-nano-gpu-demo.packages lists with their SHA-256: Mesa, libglvnd, libdrm, the X.Org and Wayland client libraries, libffi and Expat (MIT-style licences); glibc, libelf and libsensors (GNU LGPL); libgcc and libstdc++ (GNU GPL version 3 with the GCC runtime library exception); zstd (BSD); zlib. Each package's copyright file, and the GNU GPL and LGPL and the Apache licence, are in the guest under /opt/gpu/licenses (and the licences at gnu.org).
  • Source: Debian's source packages of the same versions, from snapshot.debian.org.
  • Mesa's library also names LLVM, which the Nano's driver does not use: in its place is a library of functions that do nothing, written by tools/stub_library.py.
  • The demos (demos/nano-gl) were written for sbc-emu, with its BSD licence; Rust's standard library is in the program (MIT or Apache 2.0; /opt/gpu/licenses/rust-std.html). scripts/jetson-nano-gpu-demo-fixture.sh builds the archive.

ESP32-S31: Linux flash image

  • Espressif's ESP32-S31 Linux image for the Function CoreBoard-1 (s31_full_flash.bin, served gzip'd), built unmodified with scripts/esp32s31-fixture.sh from Espressif's esp-buildroot-external d75370b (espressif_esp32s31_function_core_board_nor_defconfig) on Buildroot 2025.02.x. It holds U-Boot SPL and U-Boot, OpenSBI, Linux 6.18 and a cramfs root filesystem with BusyBox.
  • Licences: GNU GPL version 2 (Linux, U-Boot, BusyBox), BSD 2-Clause (OpenSBI), and others as each Buildroot package states.
  • Source: espressif/linux 19629799 (integration/v6.18-esp32s31), espressif/u-boot e5dff8d3 (integration/v2024.07-esp32s31), espressif/opensbi 5395e03e (integration/v1.6-esp32s31), and Buildroot 2025.02.x for the root filesystem's packages.
