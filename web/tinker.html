sbc-emu ASUS Tinker Board S

Rockchip RK3288, four 32-bit Cortex-A12s, emulated instruction by instruction in your browser

choose a system to boot

The emulated board has no USB yet, so the keyboard is the serial console: type on the screen or in the terminal below (both go to UART2, ttyS2). The screen is HDMI (VOP + DesignWare HDMI, a 720p monitor) and shows the console on tty1. The 32-bit ARM and Thumb code is translated to WebAssembly as it runs (?jit=0 interprets it).

Serial console (UART2, 115200 baud)
