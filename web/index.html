sbc-emu Raspberry Pi 4B

Linux in an instruction-level AArch64 emulator, running in your browser

choose a system to boot

Click the screen to type on the Pi's USB keyboard (emulated DWC2 USB host + HID keyboard). The screen is the firmware framebuffer (simplefb, fbcon). Try cat /proc/cpuinfo or cat /dev/urandom > /dev/fb0.

LED · GPIO17

In the guest: gpioset -t0 GPIO17_LED=1, gpioget GPIO27_BUTTON, cat /sys/bus/iio/devices/iio:device0/in_temp_input, …/iio:device1/in_voltage0_raw.
